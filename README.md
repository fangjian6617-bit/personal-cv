# 方建 · 个人主页

使用 HugoBlox Academic CV 模板制作的个人网站，内容来自方建的求职简历。

## 内容

- 个人简介、教育背景与关注方向
- 半导体设备、数据中心液冷、光模块、世界模型、游戏与 AI 应用研究
- 方正证券、上海国有资本投资、国海证券、复星高科技、容诚会计师事务所实习经历
- 进博会人工智能议题组与旅游消费行为实证研究项目
- 技能、语言能力及奖项荣誉

## 本地运行

需要 Hugo Extended、Go 与 pnpm：

```bash
pnpm install
pnpm run dev
```

## 构建

```bash
pnpm run build
```

网站通过仓库内的 GitHub Actions 工作流部署到 GitHub Pages，也保留了 Netlify 部署配置。

模板来源：[HugoBlox Academic CV](https://github.com/HugoBlox/hugo-theme-academic-cv)。
